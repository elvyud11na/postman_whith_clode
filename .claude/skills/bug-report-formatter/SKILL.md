# Форматтер баг-репортов

## Как работать

1. Собери исходные данные о баге:
   - Что делали (шаги)
   - Что ожидали получить
   - Что получили по факту
   - Откуда баг (конкретный запрос в Postman, окружение, скриншот/лог, если есть)

2. Если чего-то не хватает для полного репорта (например, неясны шаги воспроизведения) — задай 1-2 уточняющих вопроса, не додумывай сама.

3. Если баг взят из Postman-запроса (доступен через MCP) — вытащи оттуда:
   - Метод и URL
   - Тело запроса (если релевантно)
   - Фактический статус-код и тело ответа
   - Ожидаемый статус-код (из спеки/документации запроса, если есть)

4. Определи severity по умолчанию (можно предложить, но дать пользователю поправить):
   - **Critical** — падение сервиса, потеря данных, недоступность ключевого функционала
   - **High** — функционал не работает, но есть обходной путь
   - **Medium** — частичное нарушение работы, не блокирует основной сценарий
   - **Low** — визуальные/незначительные несоответствия

5. Собери репорт по структуре ниже. Если у пользователя есть свой шаблон Jira с другими полями — используй его формат вместо стандартного (спроси один раз, затем запомни на сессию).

## Формат вывода (стандартный, если нет своего шаблона)

**Заголовок:** [Модуль] Краткое описание проблемы

**Окружение:** stage / prod / dev, версия API, если известна

**Severity:** Medium

**Шаги воспроизведения:**
1. Отправить POST /users с телом {...}
2. Проверить статус-код ответа

**Ожидаемый результат:**
201 Created, тело ответа содержит id созданного пользователя

**Фактический результат:**
500 Internal Server Error, тело ответа: `{"error": "..."}`

**Дополнительно:**
Ссылка на запрос в Postman / скриншот / лог, если есть

## Что НЕ делать

- Не придумывай шаги воспроизведения, если пользователь их не описал — лучше спросить.
- Не завышай/занижай severity без явных оснований — если не уверена, предложи вариант и явно отметь, что это предположение.
- Не добавляй техническую причину бага (root cause), если не просили — баг-репорт описывает симптом, а не диагноз.
