---
description: Запускает Postman-коллекцию через Newman (локально или как для CI, с Allure-отчётом или без)
---

Запусти тесты коллекции через скрипт `run-tests.ps1` в корне проекта.

Разбери аргументы пользователя (`$ARGUMENTS`) и определи:
- `-Target`: "local" (по умолчанию) или "ci", если пользователь упомянул CI/пайплайн/git
- `-Report`: "allure", если пользователь упомянул Allure/отчёт; иначе "none"
- `-Collection` / `-Environment`: если пользователь назвал конкретный файл коллекции или окружения — передай явно, иначе используются дефолтные пути из скрипта

Выполни команду вида:
```
powershell -File run-tests.ps1 -Target <local|ci> -Report <allure|none>
```

После выполнения кратко перескажи результат: сколько тестов прошло/упало, и куда попал отчёт (если генерировался Allure).
